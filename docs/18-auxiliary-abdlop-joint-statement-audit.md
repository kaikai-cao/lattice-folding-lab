## 1. 任务 A：修正二进制余量承诺

### 1.1 x 的确切规格（长度 / 打包 / 槽位）

`[论文事实: LNP L1700, L1841]` exact 关系 `‖E_i s−v_i‖₂≤β_i^{eq}` 的二进制余量 `x⃗_i` **长度 = 2·log(β_i^{eq})** 个 bit（不是 log β），且受约束
```
2·log(β_i^{eq}) ≤ d.                                   (LNP L1700, L1841)
```
`[论文事实: LNP L134 脚注8]` 余量是整数 `β²−‖s‖²` 的二进制展开，仍是承诺值的二次关系：
> "commit to a vector ⃗b which is the binary representation of the integer β²−‖s‖² and then prove that it is indeed binary and that ⟨⃗b,(1,2,2²,…,0,…,0)⟩ is β²−‖s‖²."

`[论文事实: LNP L1778]` 每个 `x_i ∈ R_q` 是**一个环元素**：其 d 个系数装下那 `2logβ` 位（不足补零）。故 `υe` 个 exact 关系 → `υe` 个 `R_q` 元素。本阶段 `υe=1`。

`[论文事实: LNP L1719, L1759 脚注14]` x 必须进 **Ajtai 消息槽**（与 s₁ 同槽），且追加只能与 s₁ **同时**承诺：
> "the prover appends a commitment to the binary representation vector x=(x₁‖…‖x_{υe}) in the Ajtai part of the commitment to (s₁,m)."（L1719）
> "appending a commitment in the Ajtai part can only be done at the same time as the commitment to s₁. If for some reason it is not possible to commit ahead of time to ⃗x, one has to commit to ⃗x in the BDLOP part instead."（L1759，脚注14）

`[论文事实: LNP L1768–1772, L1814]` Fig10 公开矩阵 `A₁∈R_q^{n×(m₁+υe)}`，消息块写作 `[s₁ x]`——直接印证"Ajtai 槽扩列装 x"。

`[论文事实: LNP L1704 Lemma 5.2, L1710, L1717]` 二值性由 `⟨x′,x′−1⃗⟩=0 mod q`（Eq.58）经 Fig9 approximate range proof 提升到整数后，用 Lemma 5.2（`⟨x⃗,x⃗−1⃗⟩=0 ⇒ x⃗∈{0,1}ⁿ`）推出；条件 `B²+(υe+k_bin)dB<q`（L1717）。

### 1.2 σ(s₂) 是由 s₂ 决定的自同构映像，不是可独立选择的秘密变量

`[论文事实: LNP L1690, L1814–1816]` §5.2 的 witness 向量写作 `s=(s₁,σ(s₁),m,σ(m))`，形式上是 `2(m₁+ℓ)` 维；但 σ 分量**不是自由变量**：协议把挑战限制在 σ 不动集 `σ(c)=c`（L141），验证者检验 `σ(z)·z−c²β²`（Eq.11, L143），其 c² 系数即为 `σ(s)·s−β²`。因此提取器得到的 `σ(s₁)` 必是 `s₁` 的自同构像。

`[推导]` 对 s₂ 同理：若 s₂ 进入 exact 证明，`σ(s₂)=s₂(X^{−1})` **由 s₂ 唯一决定**。构造时不得把 `σ(s₂)` 当作可与 s₂ 不一致的独立秘密变量，否则破坏 Eq.(11) 的可靠性论证。本阶段所有 statement 中，s₂ 只出现一次（作为消息），其 σ 像由协议内部约束，不单列承诺。

## 3. 任务 C：重做同一性与安全性分析

### 3.1 严格区分三件事

用户要求把三件事分开，本阶段明确如下：

1. **关系定义用同一个 s₂**：在 (R1)(R2)(R3) 中写的是同一个符号 s₂，这是**定义层的同一**， trivially 成立，但**不产生任何安全保证**。
2. **单次联合 PoK 能否提取满足全部联结关系的共同 witness**：这是**协议层**问题。只有当 (R1)+(R2)+(R3) 被装进一个对联结关系知识可靠的 PoK、且存在**单一提取器**输出 `(s̄₁,s̄₂,x̄,m̄,…)` 同时满足三式时，才成立。B1 的两个独立证明**不满足**此条；B2 的单 statement 结构**有望满足**，但需 §2.3 的 `[待核查]` 闭合。
3. **原始与辅助承诺各自的 binding**：这是**假设层**问题，与 2 独立。见 §3.3。

`[推导]` 因此正确陈述是：
```
accepting transcript
  → [联合 PoK 提取器] → (s̄₁,s̄₂,x̄,m̄,r̄) 满足 (R1)(R2)(R3)   [协议层, B2 待证]
  → exact 界 ‖s₂‖₂≤β 作用于该 s̄₂                            [由 R3]
  → s̄₂ 是主承诺 t_A 的一个短 opening                        [由 R1 + 原始 binding]
```
**不是**"两个证明各提一个 s̄₂ 再假设相等"。

### 3.2 差向量与实际范数上界

`[推导]` 设两个可接受 opening 的盐分别为 (s₁,s₂)、(s'₁,s'₂)，定义
```
Δs₁ = s₁−s'₁,  Δs₂ = s₂−s'₂,  Δx = x−x',  Δr = r−r'
```
须分三种界，不能混用：
```

   ‖s₂‖₂ ≤ β_honest (≈√(m₂·d) 量级；B̃=2, LBF L2876)
协议提取 relaxed opening（Lemma 3.1 st.2, c̄-scaled）:
   ‖s̄_i·c̄‖₂ ≤ 2s_i√(2m_i d)     ← 只对乘积给界，非 ‖s̄_i‖
binding 用的差向量界（乘 c̄c̄' 清分母, L511–521）:
   ‖(s̄_i−s̄'_i)·c̄c̄'‖ 相关短量 z̄_i c̄'−z̄'_i c̄ 界为 8η·s_i√(2m_i d)
exact 覆盖的 s₂（B2 的 (L4)(L5)）:
   ‖s̄₂‖₂ ≤ β  无 c̄   ← exact 核心收益，但仅覆盖被 exact 关系作用的 s₂
```
`[推导 · ★LB-05T 纠正]` 因此 MSIS 界 B 的取值依据**不是**未证的 `2β_s`，而是：若对应分量只走 relaxed 提取，B 取 c̄-scaled 上界 `8η√(…)`；**若该分量被 exact 覆盖（B2 的 s₂），也不能取裸 β**——`‖s̄₂‖≤β` 是单 opening 谓词，binding 双 opening 差仍带 c̄c̄′ 放大，该项界为 `2β‖M_c̄M_c̄′‖_{2→2}≤8η²β`。s₁、r 未被 exact 覆盖，仍带 c̄。Δx 二值差本文按 `‖Δx‖₂≤√υe·d` 保守计（strict 路径下亦乘挑战差，见 docs/21 §1.3(c)）。单次 s₂ 无 c̄ ≠ 递归无 c̄（docs/15 边界）。完整混合界与三层 binding 见 docs/21。

### 3.3 binding：原始 / 辅助 / 组合矩阵三种，不能混为一谈

`[推导]` **修正用户指出的过强表述**：MSIS 不是"无条件保证 witness 唯一"，而是——给定矩阵分布适当、`m>n`、界 B 满足 `MSIS_{n,m,B}` 假设时，找到非零短 z（`‖z‖≤B, Az=0`）是**计算困难**的。依赖三个前提：(a) 矩阵分布；(b) 维度 n,m；(c) B 相对 q、n、m 的比例。若 B 过大或矩阵非均匀分布，可平凡失败。故正确说法是"在 MSIS_{n,m,B} 假设下，找到两个不同短 opening 计算困难"。

**(a) 原始 LBF binding**（主承诺，MSIS on [A₁ A₂]）：
若 (s₁,s₂,m)、(s'₁,s'₂,m') 同为 t_A,t_B 的 opening，则
```
A₁Δs₁ + A₂Δs₂ = 0,        BΔs₂ + Δm = 0
```
m 是无限制消息，Δm 可吸收 BΔs₂ → 第二式对 s₂ **不施加**短约束；binding 只来自第一式，即短向量 `(Δs₁,Δs₂)` 落在 `[A₁ A₂]` 的核：需 `MSIS_{n, m₁+m₂, B}` 成立，其中 B 按 c̄-scaled 提取界取值（relaxed 分量用 `8η·s_i√(2m_i d)`，exact 覆盖的 s₂ 可用 β；**不用未证的 2β_s**，见 §3.2 LB-05S 修正与 docs/19 §3.5）。s₂ 唯一 ⇒ m=t_B−Bs₂ 唯一。

**(b) 辅助承诺 binding**（B1，MSIS on [A'_s A'_x A'_r]）：
若 (s₂,x,r,m')、(s'₂,x',r',m'') 同为 t'_A,t'_B 的 opening，则
```
A'_s Δs₂ + A'_x Δx + A'_r Δr = 0,      B'Δr + Δm' = 0
```
同理 m' 吸收 B'Δr；约束为 `MSIS_{n', m₂+υe+m₂', B}`，B 取 §3.2 上界。

**(c) 组合矩阵是否都要**：在 B2 单个 statement 里，(R1) 把 ŝ₁ 绑到 t_A，(R2) 把 ŝ₁ 与 m̂ 绑到 t_B。若存在两个不同 ŝ₁ 满足联结，则
```
[A₁ A₂ 0]Δŝ₁ = 0   →  A₁Δs₁ + A₂Δs₂ = 0   （与 (a) 同一 MSIS）
[0 B 0]Δŝ₁ + Δm̂ =0 →  Δm̂ 吸收，不额外约束
```
`[推导]` 结论：B2 **不需要**构造一个合并的大矩阵 MSIS；而是**同时需要**两层——辅助承诺 binding（保证提取的 ŝ₁ 是 t̂ 的短 opening，`MSIS_{n',m₁+m₂+υe+m₂'}`）**与**原始 binding（保证满足 R1 的短 opening 唯一，`MSIS_{n,m₁+m₂}`）。二者作用不同、不能互相替代；"共享变量"不提供任何一层。

### 3.4 c̄ 对提取界的影响

`[论文事实: LBF L1308–1320, L2154–2159]` Π_many（Fig4）提取 `(s̄₁,s̄₂,c̄)`，其中 c̄ 是两个 accepting transcript 的挑战差，界为
```
‖c̄·s̄_i‖₂ ≤ 2 s_i √(2 m_i d),    i=1,2        （relaxed，带 c̄）
```
且 `c̄⁻¹` 存在但**不一定短**（LBF L2155–2159），故不能除以 c̄ 得到 `‖s̄₂‖` 的紧界。

`[论文事实: LNP L1696 Eq.53, L1727–1729]` §5.2 的 exact 界 `‖E_i s−v_i‖≤β_i^{eq}` **不带 c̄**——它通过二进制余量 + 整数提升（Eq.58/59/60）绕开除以 c̄。这正是 exact 相对 relaxed 的核心收益，也是 Remark 4.8 想去掉 c̄ 因子的原因（LBF L3135）。

`[推导]` 在 B2 联合 statement 中：
- 被 `E_{s₂}` exact 覆盖的 s₂：提取界 `‖s₂‖₂≤β`，**无 c̄** ✓；
- **未**被 exact 覆盖的盐（如 ŝ₁ 中的 s₁、新 randomness r）：仍走 relaxed，界带 c̄，**不能**宣称无 c̄；
- 因此 B2 默认只给 s₂ 去 c̄；若要 s₁、r 也无 c̄，需各加 `E_{s₁}`、`E_r` exact 关系（υe 增大、参数重推），本阶段不包含。
- **单次正确 ≠ 递归正确**：即使 s₂ 单次无 c̄，跨轮 binding 识别同一 opening 与无累积链仍未证明（沿用 docs/15 边界）。

## 4. 任务 D：两处 fresh salt 的适用性与成本

### 4.1 需要多少份辅助承诺

`[论文事实: LBF L2883–2893, L2775–2777]` 两处 PoK 均为"消息恒等式 exact（Lemma3.6(3)）+ 盐 relaxed（Lemma3.6(2)）"：

| 位置 | fresh salt | 辅助承诺份数 |
|---|---|---|
| Protocol 8 Step 5（输出盐） | `s_{2,i,j}`，`N_c=(k+1)t` 个承诺串接 | **`(k+1)t` 份** |
| Protocol 7 Step 17（mask 盐） | `s_{2,y,j}`，每个 j∈[t] | **`t` 份** |
| 合计 | — | **`(k+2)t` 份** |

`[推导]` k、t 未给具体值（LBF k=31 见 LB-01 记录；t 为复用参数），故份数为符号级 `(k+2)t`。

### 4.2 二进制向量带来的新增 Ajtai 消息维度

`[推导]` 每份辅助承诺因追加 x 新增 **υe=1 个 R_q 环元素** = **d 个 Z_q 系数**：

| 版本 | 原 Ajtai 消息维度 | 加 x 后 | d=128 | d=64 |
|---|---|---|---|---|
| B1 | m₂ | m₂+1 | 53 → **54** | 83 → **84** |
| B2 | m₁+m₂ | m₁+m₂+1 | m₁+53 → m₁+54（m₁ 未定） | m₁+83 → m₁+84 |

`[推导]` 打包位数 `2logβ≈13`（§1.4）远小于 d，1 个环元素足够，不额外增加环元素数。

### 4.3 区分"新增长度"与"新增长度以外的公共承诺元素数"

`[推导]` 必须分开两类增量，不能混算：
- **新增长度（消息维度）**：B1 为 `+1` 个 R_q 元素（消息向量长度 m₂→m₂+1）；这是 witness 侧。
- **公共承诺元素数（矩阵）**：为支撑该列，公开矩阵 `A'_1=[A'_s A'_x]∈R_q^{n'×(m₂+1)}` 含 `n'(m₂+1)` 个 R_q 元素，其中 x 列贡献 `n'×1=n'` 个环元素；再加 `A'_r` 的 `n'·m₂'`、`B'` 的 `ℓ'·m₂'`。这些是**公钥/公共承诺侧**，与 witness 长度不同维度，不得相加混称。

### 4.4 维度代入（d=64/128, m₂=83/53）

| 项 | d=128 (m₂=53, n+ℓ=27) | d=64 (m₂=83, n+ℓ=35) |
|---|---|---|
| B1 Ajtai 消息维度 (含 x) | 54 | 84 |
| B1 `A'_1` 环元素数 | `n'×54`（x 列 `n'`） | `n'×84`（x 列 `n'`） |
| B1 二进制 x 的 Z_q 系数数 | 128/元素 | 64/元素 |
| 辅助承诺份数 | `(k+2)t` | `(k+2)t` |
| B2 Ajtai 消息维度 | m₁+54 | m₁+84 |

### 4.5 无法数字化的项（n', m₂' 未选）

`[推导]` 以下成本**无法数字化**，仅符号级：
- 辅助承诺行数 n'、randomness 维度 m₂'、BDLOP 消息长度 ℓ' 未选 → 公钥矩阵元素总数、承诺大小、PoK 转录大小均不能给具体数；
- k、t 未给值 → 辅助承诺总份数 `(k+2)t` 不能数字化；
- Thm5.3 参数（B^{(eq)}, c^{(eq)}, k_bin, q）未按新消息维度重推 → proof size 不虚报（遵守 LB-04"不以估计证明大小代替参数计算"禁令）。

### 4.6 保持两处盐的不相交性

`[论文事实: LBF L3642–3643, L3648–3649]` LBF 刻意让 mask 承诺各块 fresh salt 对互不相交、且与 `{C_{y,j}}` 的盐不相交，`C_{y,0}` 从不与其他承诺同态组合。
`[推导]` B1/B2 的辅助承诺必须**逐块独立**为每份 fresh salt 建承诺，不得跨块共享 witness 或合并，否则破坏 LBF blinding 论证。这与 §4.1 的"每盐一份"一致。

## 5. 任务 E：最终决策

**选择 B2（作为下一阶段研究路线，非安全性结论）**，理由：

| 判据 | B1 窄版 | B2 扩展版 |
|---|---|---|
| s₂ 可被公开矩阵 R₁ 乘（Eq.6 合法输入） | ✗（s₂ 是 randomness，只能经 m=t_B−Bs₂ 隐式进入） | ✓（s₂ 在 ŝ₁，Ajtai 消息） |
| 原始 opening 与 exact 进同一 statement | ✗（需两个证明联合提取，用户质疑未解） | ✓ 结构层命中五接口（§2.3） |
| 差向量 binding 分析 | 需辅助 + 原始两层 | 需辅助 + 原始两层（§3.3(c)，无合并大矩阵） |
| 主要风险 | 联合 PoK 未构造 | 三个 `[待核查]` + 参数重推 |

`[推导]` B2 更贴合用户"利用 LNP22 原生线性关系把原始 opening 与 exact-norm 放进同一可提取 commit-and-prove 关系"的目标。但**必须强调**：
- B2 只是**候选构造**；§2.3 三处 `[待核查]`（扩展维度 E_i 接口兼容、x 双重角色、Thm5.3 参数重推）任一失败即退回 C；
- 本决策**不是**安全性结论，不声称已证明知识可靠性、已实例化、已实现；
- 不选 B1：其联合提取缺口正是用户本轮核心质疑，未解决；
- 不选 C：B2 在结构层逐接口命中原文，尚不构成"两种方式都无法形成严谨关系"的否定。
