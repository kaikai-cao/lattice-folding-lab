## E1B. Theorem 5.3 的承诺实例映射：n_Thm = n′（任务 B）

`[推导]` B2 的 Fig10 联合 statement（docs/20 §0）以**辅助承诺**为提取承诺：`t̂_A=Â_s s_A+Â_x x+Â_r r`、`t̂_B=B̂ r+m_A`。Thm5.3 的假设对象是"an ABDLOP commitment to a message (s₁,m)∈R_q^{m₁+ℓ} with randomness s₂∈R_q^{m₂} satisfying A₁s₁+A₂s₂=t_A, Bs₂+m=t_b"——这里的 `(t_A,t_b)` 就是**被提取的承诺**。原始 LBF 关系 `A₁s₁+A₂s₂=t_A, Bs₂+m=t_B` 在 B2 联合 statement 中是**关于消息的公开线性关系 (L1)**（Fig10 (50) 类约束），**不是**提取承诺本身。

**二选一结论：采用方案 1（单个辅助 ABDLOP 承诺实例）**，逐项代入：

```
n_Thm  = n′       （辅助承诺 Ajtai/BDLOP 行数，Â_s/B̂ 的行数）
m₁,Thm = M_Ajtai  （辅助 Ajtai 消息总列数，§E1C）
ℓ_Thm  = ℓ′       （辅助 BDLOP 消息维度，暂取 ℓ）
m₂,Thm = m₂′      （辅助 randomness r 的维度；原文 s₂ 角色由 r 承担）
s₂,Thm = r        （原文 Extended-MLWE 秘密 s₂ → B2 新盐 r；B2 的 s₂ 已是消息、不在此秘密位）
```

**不选方案 2（组合两个承诺）**：本轮不需要把原始承诺与辅助承诺拼成 Thm5.3 的单个承诺——(L1) 已在联合 statement 内作为公开关系被同一提取器验证（docs/20 §1.3），Thm5.3 的 n 只对应被提取的辅助承诺。若未来改设计确实需要组合承诺，必须显式写出组合矩阵、总行数、随机变量维度与关系接口，不得只写"再增加 n′"。

按方案 1 **重写完整 Extended-MLWE 实例**（原文 PDF L6275–6277，印刷页 45 视觉）：

```
Extended-MLWE_{ n′+ℓ′+λ+2(256/d+1),  m₂′−n′−ℓ′−λ−2(256/d+1),  χ, C, r }
```

对应 hiding 条件（原文层级，逐项保留 `+1`、`λ`、`2(256/d+1)`）：

```
m₂′ > n′+ℓ′                              （承诺 hiding）
m₂′ > n′+ℓ′+1                            （commit-and-prove，+1 来自 bᵀ/Rej₂）
m₂′ > n′+ℓ′+λ+2(256/d+1)                 （Thm5.3 simulatability，上式采用）
```

`[推导]` **两个问题严格分开**：(a) 辅助 ABDLOP 的 hiding / Extended-MLWE 条件（上式，参数 n′,m₂′,ℓ′,λ,d）；(b) 原始 LBF 承诺与辅助承诺的 MSIS binding 条件（docs/21，`MSIS_{n,m₁+m₂,B_orig}` 与 `MSIS_{n′,M_Ajtai+m₂′,B_aux}`）。**不得把辅助 Extended-MLWE 的 n′/m₂′ 当成原始承诺的 binding 参数**，反之亦然。这是 LB-06 旧稿"一边区分 n/n′、一边 Extended-MLWE 仍写 n+ℓ+…"的修正。

## E1D. exact challenge dimension c^(e) 与 C1/C2/C3 的计数分离（任务 D）

`[论文事实: PDF L6020–6027 Fig10 输入参数，印刷页 45 视觉]` `c^(d)=d·Σ_{i=1}^{υ_e}k_i`，**`c^(e)=d(k_bin+Σ_{i=1}^{υ_e}(p_i+1))`**。`p_i` 是 E_i 输出的 **R_q 元素数**（不是系数数：d 已在最外层），`+1` 对应每个关系的 1 个二进制余量 R_q 元素。B2 的 E_{s₂}^{(i)} 选一个盐块的 m₂ 个 R_q 分量 ⇒ `p_i=m₂`，k_bin=0：

```
c^(e) = d · (0 + υ_e·(m₂+1)) = d·υ_e·(m₂+1),   υ_e=(k+2)t
```

**D2 · C2 的 υ_e+k_bin 来源（与 c^(e) 分开）**：C2 是整数提升条件，保证二值拼接向量在 Z 上不回绕；其根号项只数**余量个数 υ_e 与 Eq.(54) 独立二值约束数 k_bin**，即 `√((υ_e+k_bin)d)`（d 在根号内），**与 E_i 的输出维数 p_i 无关**。p_i 只通过 `c^(e)` 进入 C1 与 Lemma 2.9 的 rejection sampling，**不进入 C2**。因此"challenge dimension 随 Σp_i 增大"并不改变 C2 的根号计数——两个公式都涉及 exact-norm，但计数对象不同，**严禁把 Σp_i 代入 C2 根号或把 C2 的 υ_e 当成 Σp_i 的简记**。

## E2. Theorem 5.3 全部不等式代入（印刷页 45 视觉确认）

原文三条条件（PDF 页45 视觉逐字）：

```
(C1)  B^(e) < q / (41 c^(e))
(C2)  (B^(e))² + √((υ_e + k_bin) · d) · B^(e) < q   ← d 在根号内（LB-06R2 纠正）
(C3)  2 · (max_{i∈[υ_e]} β_i^(e))² + (B^(e))² − 1 < q
```

`[推导]` B2 代入与逐项说明：

`[推导]` **B2 代入的完整账本、变量来源与增长依赖已在 §E1D 表逐项给出**，此处只列结论与旧判断的撤回：

**(C1)** B^(e) 视觉定义为 `2√(256/26·t·γ^(e))·√337·α^(e)`（**不是**旧稿的除式）；`c^(e)=d·υ_e·(m₂+1)` 随 υ_e **线性增长**。旧稿称"c^(e) 不随 υ_e 变、C1 不是瓶颈"——**已撤回**：给定 q 必须压低 B^(e)（增大 α^(e)），C1 随 υ_e 收紧，并与 C2/C3 的 q 下界相互牵制。

**(C2)** 二值提升条件：`(B^(e))² + √((υ_e+k_bin)d)·B^(e) < q`（**d 在根号内**；LNP22 原文陈述与 soundness proof 两处一致，LB-06R2 撤回 LB-06R 的"根号外"误记）。
- B2 代入 υ_e=(k+2)t、k_bin=0：根号项 `√((k+2)td)·B^(e)`，按 `√((k+2)td)=√(k+2)·√t·√d` 增长（随盐块数 √t、随环维度 √d）。**不是** `√((k+2)t)·d`——旧误写把 d 移出根号，在 d=64/128 时把 C2 第二项分别放大 8 倍 / ≈11.31 倍，高估了 B2 的参数成本。
- 这是"exact 关系数放大"的第一处；此处只数 υ_e 与 k_bin 的**关系数**，不数 E_i 输出维数 p_i（计数分离见 §E1D/E2b）。

**(C3)** 整数提升条件：`2(max β_i^(e))² + (B^(e))² − 1 < q`。
- B2 代入 `max β_i^(e) = max(β_step5, β_step17)`（docs/20 §2.5：用较大者可同时满足两组）。
- β_step5/β_step17 含 (m₁+m₂)d 或 √(m₁+m₂)d 因子（LBF Remark 4.8），随 m₁\*=m₁+m₂ 增长；这是"消息维度放大"进入 q 下界的地方。
- **β 官方表达式已取得**（LBF 印刷页 47 视觉）：`β_step5=√kt(B̃−1)√((m₁+m₂)d)`、`β_step17=(B̃−1)√(t(m₁+m₂)d)`，两者均为 √((m₁+m₂)d) 量级，故 `2β²` 按 **(m₁+m₂)d** 量级增长（不是旧稿担心的 (m₁+m₂)²d²）；但 `B̃` 定义与单块/整批口径未闭合，原文亦标 "we do not instantiate"，故 C3 仍不能视为已定型。

### E2b. `Σp_i` vs `υ_e`（LB-06R：已闭合，不再列为阻断）

`[推导]` 旧疑点"υ_e 是否 = Σp_i 简记"已由原文两处独立定义排除：
- `c^(e)=d(k_bin+Σ(p_i+1))`（L6020–6027）：数 E_i 输出的 R_q 元素 + 每关系 1 个余量元素，每元素 d 系数 → 进入 **C1 与 Lemma 2.9 rejection sampling**；
- C2 根号 `√((υ_e+k_bin)d)`：数 exact 关系个数 + Eq.(54) 独立二值约束个数与环维度 d（**d 在根号内**）→ 进入**整数提升**。

两者计数对象不同，**不存在"υ_e=Σp_i"的替换关系**；系数展开 `d(k_bin+Σ(p_i+1))` 不能移植成 C2 的修正。B2 下 `Σp_i=υ_e·m₂` 只放大 c^(e)/C1，C2 仍按 υ_e=(k+2)t 计。原文 Eq.(61) 的 e^(e) 拼接（L5805–5839）对应第一类的挑战/拒绝抽样向量，与 C2 的第二类计数来源不同——旧稿据此提出的"√m₂ 倍 q 下界疑点"不成立，**本项已从 HOLD 阻断清单移除**。

### E2c. Extended-MLWE 参数（LB-06R：按 §E1B 方案 1 重写）

Thm5.3 simulatability（L6275–6277）：模拟承诺/转录与真实的区分优势 ≤ ε/2 − 2^{−100}，归约到
```
Extended-MLWE_{ n+ℓ+λ+(256/d+1)+(256/d+1),  m₂−n−ℓ−λ−(256/d+1)−(256/d+1),  χ, C, s₂ }
```
`[推导]` B2 按 §E1B 方案 1 逐项替换（**n_Thm=n′，不再留"若独立建模再加 n′"的选项**）：

| Extended-MLWE 维度 | 原文 | B2 替换 | 变化 |
|---|---|---|---|
| 承诺行数（n_Thm） | n | **n′**（辅助承诺行数） | 提取承诺=辅助承诺；原始 L1 是公开关系、不是提取承诺 |
| BDLOP 消息维度（ℓ_Thm） | ℓ | ℓ′=ℓ | 暂取相同 |
| challenge 维度 | λ | λ 不变 | 来自 Γ∈Z_q^{λ×M} |
| 随机变量维度 | m₂−n−ℓ−λ−2(256/d+1) | **m₂′−n′−ℓ′−λ−2(256/d+1)** | 新盐 r 承担原文 s₂ 角色；须 > 行数 |
| 秘密 | s₂ | **r** | B2 的 s₂ 已是 Ajtai 消息、不在此秘密位 |
| 完整实例 | — | `Extended-MLWE_{n′+ℓ′+λ+2(256/d+1), m₂′−n′−ℓ′−λ−2(256/d+1), χ, C, r}` | 见 §E1B |

`[推导]` B2 的 hiding 条件（修正 docs/17 旧 `m₂′>n′`）：按原文层级
`m₂′ > n′+ℓ′`（承诺）→ `> n′+ℓ′+1`（commit-and-prove，+1 来自 b^T/Rej2）→ `> n′+ℓ′+λ+2(256/d+1)`（Thm5.3 simulatability）。**第二个「+1」和 λ、2(256/d+1) 不能省**，且行数一律用 n′（辅助承诺），不再写 n。**辅助承诺 Extended-MLWE hiding（本表）与原始/辅助承诺 MSIS binding（docs/21）是两个不同问题**；`M_Ajtai=m₁+m₂+υ_e` 进入 B_aux 的 MSIS 列数，不是这里的 n′/m₂′。新实例 hardness 未估，仍为 HOLD 阻断。

## E3. 参数可行域判断（符号级 + LBF 参数保守检查）

### E3.1 是否存在同时满足全部条件的参数区域

`[推导]` **符号级无硬矛盾**（LB-06R）：自由参数 (q, m₂′, n′, α^(d),α^(e),γ1..γ4, B̃, k,t) 可协调，但 c^(e) **不是**自由参数：
1. `c^(e)=d(k+2)t(m₂+1)` 由 Fig10 定义固定（§E1D），C1 要求 `B^(e)<q/(41c^(e))`，给定 υ_e 后须靠压低 B^(e)（增大 α^(e)）或增大 q 满足；
2. 按 §E1B/E2c 选 `m₂′>n′+ℓ′+λ+2(256/d+1)`（hiding）且 m₂′ 足够大使 `MSIS_{n′,M_Ajtai+m₂′,B_aux}` 难（B_aux 含 s₂ exact 项，docs/21 §1.4）；
3. 按 C2/C3 选 `q > max{(B^(e))²+√((k+2)td)·B^(e), 2(max β)²+(B^(e))²−1}`；
4. α 参数按 L6726–6737 协调（γ 大⇒中止概率低但 s 大⇒ MLWE 实例松）。

**无硬矛盾但相互牵制**：C1 给 B^(e) 上界、C2/C3 给 q 下界，且 c^(e) 随 υ_e 增长会同时收紧 C1；增大 q 总可满足不等式（在格硬度允许范围内），但需具体 hardness 估算确认实例规模可承受。

### E3.2 与 LBF 原始参数的兼容性（保守检查）

```
LBF 参数（Table2）：d=128 → n+ℓ=27, m₂=53；d=64 → n+ℓ=35, m₂=83
B2：M_base=m₁+m₂（m₁≈n），M_Ajtai=M_base+υ_e，υ_e=(k+2)t（k,t 未选定）
```

`[推导]` 保守代入（**符号级，不虚报数值**）：
- Ajtai 消息从 m₁ 增到 `M_Ajtai≈m₁+m₂+υ_e`（约翻倍再加余量）：Fig10 的 E_i 列数与 B_aux 列数随之增长；但 hiding 条件 `m₂′>n′+ℓ′+…` 只约束**新盐** r，与 s₂ 的消息提升**正交**——不是"秘密维度翻倍破坏 hiding"；
- exact 关系数 υ_e=(k+2)t：C2 根号项 `√((k+2)td)`（d 在根号内，按 √((k+2)td) 增长）；C1 的 c^(e)=d(k+2)t(m₂+1) 随 υ_e **线性**增长——这是 LB-06R 新识别的增长点；
- β_step5=√kt(B̃−1)√((m₁+m₂)d)、β_step17=(B̃−1)√(t(m₁+m₂)d)（官方 PDF，印刷页 47 视觉）：`2β²` 按 (m₁+m₂)d 量级（**不是**旧稿的 (m₁+m₂)²d²）；主导瓶颈变为 c^(e) 增长 + B̃ 未定 + 新 Extended-MLWE 实例 hardness。

### E3.3 增长量级（LB-06R 修订：旧 Σp_i 疑点已闭合）

- `c^(e)=d(k+2)t(m₂+1)` 随 υ_e 线性增长 ⇒ C1 `B^(e)<q/(41c^(e))` 收紧（旧稿"宽松"判断撤回）；
- C2 根号项 `√((k+2)td)`，d 在根号内 ⇒ q 下界按 `√(υ_e·d)` 增长（不是 `√υ_e·d`；后者高估约 √d 倍）；
- `2β²` 按 `(m₁+m₂)d·(B̃−1)²·max(k,1)` 量级（官方 β 表达式），非旧稿的 `(m₁+m₂)²d²`；但 `B̃` 定义与单块/整批口径未定，系数仍不可确定；
- E2b 的"Σp_i 误置入 C2"已被原文两处独立定义排除，不再列为增长来源。

### E3.4 代价落点

| 资源 | 增长来源 | 量级（符号） |
|---|---|---|
| 承诺大小 | s_A 增 m₂ 列 + υ_e 个余量 R_q 元素 + 辅助承诺 | +m₂ + υ_e 个 R_q 元素（每个 d·log q bit） |
| proof size | z^(e)（维数随 e^(e) 拼接长度）、c^(e) | 随 Σp_i+υ_e 增长；c^(e) 受 C1 限 |
| prover time | 多个 E_i 作用 + 拒绝抽样重抽 | 随 υ_e 线性 |
| verifier time | 多 E_i 验证 + MSIS/Extended-MLWE 参数变大 | 随 υ_e 线性 + q 增大 |
| 主导瓶颈 | C1 的 c^(e)=dυ_e(m₂+1) 增长 + B̃ 未定 + 新 Extended-MLWE hardness | 可能使 q 与实例规模陡增（待量化确认） |

### E3.5 数值瓶颈结论

`[推导]` **不能宣称 128-bit**：(a) β 官方表达式已取得但 `B̃` 定义与单块/整批口径未定；(b) E2b 计数对账**已闭合**（不再阻断）；(c) 具体 MSIS/Extended-MLWE hardness 未估；(d) 论文 ε 条件内部不一致、证明页缺裕量（§E0）；(e) 时间符号三处未证等同。在这些之前给出任何具体安全级别都无依据。**也没有证据表明 B2 必然不可行**——瓶颈是"待量化的增长 + 论文内部不一致"，不是"已证实的结构矛盾"。
