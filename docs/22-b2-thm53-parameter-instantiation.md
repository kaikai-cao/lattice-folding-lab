## E2. Theorem 5.3 全部不等式代入（印刷页 45 视觉确认）

原文三条条件（PDF 页45 视觉逐字）：

```
(C1)  B^(e) < q / (41 c^(e))
(C2)  (B^(e))² + √( (υ_e + k_bin) · d ) · B^(e) < q
(C3)  2 · (max_{i∈[υ_e]} β_i^(e))² + (B^(e))² − 1 < q
```

`[推导]` B2 代入与逐项说明：

**(C1)** `B^(e) = 2√(256/26)·γ^(e)/(√337·α^(e))`。约束挑战矩阵列数 c^(e)：`c^(e) < q/(41 B^(e))`。B2 中 c^(e) 不随 υ_e 变（挑战矩阵 Bin_{256×c^(e)} 的列数是独立的），故 C1 相对宽松——只要 q 足够大、α^(e) 不太小即可。**不是瓶颈**。

**(C2)** 二值提升条件：`(B^(e))² + √((υ_e+k_bin)d)·B^(e) < q`。
- B2 代入 υ_e=(k+2)t、k_bin=0（或新增值）：根号项 `√((k+2)t·d)·B^(e)` 随盐块数 **√t 增长**。
- 这是"exact 关系数放大"的第一处：υ_e 从原文典型值（VE 场景 υ_e=1）增到 (k+2)t，C2 的 q 下界抬高约 √((k+2)t)。

**(C3)** 整数提升条件：`2(max β_i^(e))² + (B^(e))² − 1 < q`。
- B2 代入 `max β_i^(e) = max(β_step5, β_step17)`（docs/20 §2.5：用较大者可同时满足两组）。
- β_step5/β_step17 含 (m₁+m₂)d 或 √(m₁+m₂)d 因子（LBF Remark 4.8），随 m₁\*=m₁+m₂ 增长；这是"消息维度放大"进入 q 下界的地方。
- **若 β 含 (m₁+m₂)d（非根号）**，则 `2β² ~ 2(m₁+m₂)²d²·(...)²`，q 需按 (m₁+m₂)² 量级增长——这是潜在瓶颈（增速取决于 β 的官方表达式，待核查）。

### E2b. `Σp_i` vs `υ_e` 维度计数对账（用户任务 C2 的核心疑点）

用户任务给的系数展开计数 `d(k_bin + Σ_{i=1}^{υ_e}(p_i+1))` 与原文 `√((υ_e+k_bin)d)` **计数单位不同**：
- 原文(C2)：以 **υ_e（关系数）+ k_bin（二值约束数）** 计，每个关系贡献的不是 p_i 而是被 υ_e 抽象吸收；
- 用户式：以每个 E_i 的 **p_i 个输出 R_q 元素 + 1 个余量元素**、每元素 d 系数计，得 `Σ(p_i+1)` 个 R_q 元素 → 系数级 `d·Σ(p_i+1)`。

`[推导]` 若 B2 每个 E_{s₂}^{(i)} 选一个盐块的 m₂ 个 R_q 分量（p_i=m₂），则 `Σp_i = υ_e·m₂ ≫ υ_e`——两种计数差 m₂ 倍！这不是记号差异而是**实质问题**：
- 若原文 C2 的 υ_e 已隐含"每个关系可输出 p_i 维向量"（即 e^(e) 向量总维数是 Σp_i 而非 υ_e），则 B2 的 C2 应代入 `Σp_i + k_bin ≈ (k+2)t·m₂`，而非 υ_e=(k+2)t——q 下界的根号项从 `√((k+2)t·d)` 放大到 `√((k+2)t·m₂·d)`；
- `[待核查 · 决定可行域]` 需查 Fig10 的 e^(e) 定义（PDF L5805–5839 Eq.(61)）与 Thm5.3 证明 C2 的来历（L6562–6567），确认原文 `υ_e` 是否 = Σp_i 的简记。**本轮无法闭合**（文本流 Eq.61 显示 e^(e) 拼接所有 E_i 输出与 x_i，暗示总维数是 Σp_i+υ_e，但 Thm5.3 条件只写 υ_e+k_bin，二者关系未明）。这是列 B2-PARAM-HOLD 的首要原因。

### E2c. Extended-MLWE 参数（PDF 页45 视觉确认）

Thm5.3 simulatability（L6275–6277）：模拟承诺/转录与真实的区分优势 ≤ ε/2 − 2^{−100}，归约到
```
Extended-MLWE_{ n+ℓ+λ+(256/d+1)+(256/d+1),  m₂−n−ℓ−λ−(256/d+1)−(256/d+1),  χ, C, s₂ }
```
`[推导]` B2 替换（任务 E3，逐项）：

| Extended-MLWE 维度 | 原文 | B2 替换 | 变化 |
|---|---|---|---|
| 矩阵行数 | n+ℓ+λ+2(256/d+1) | **n+ℓ′+λ+2(256/d+1)**（+ 辅助承诺行数 n′ 若独立建模） | ℓ′=ℓ 不变；若辅助承诺的 masking 另加行则增大 |
| 随机变量维度（秘密长度） | m₂−n−ℓ−λ−2(256/d+1) | **m₂′−n−ℓ′−λ−2(256/d+1)** | 用 m₂′（新盐），须 > 行数（hiding），即 `m₂′ > n+ℓ+λ+2(256/d+1)` |
| challenge 维度 | λ（来自 Γ∈Z_q^{λ×M}） | λ 不变 | — |
| 辅助承诺消息维度 | —（原文无） | s_A 含 s₂，维度 m₁+m₂；余量 υ_e 个 | 若辅助承诺并入同一 ABDLOP（docs/20 §1.3），其消息维度进入 masking 矩阵 B^(e) 的作用对象 |
| 具体参数 | Extended-MLWE_{n+ℓ+λ+2⌈256/d+1⌉, m₂−…, χ,C,s₂} | Extended-MLWE_{n+ℓ+λ+2⌈256/d+1⌉, m₂′−…, χ,C,r}（r 为新盐） | **s₂ 角色由 r 承担**；B2 的 s₂ 已是消息、不在此秘密位 |

`[推导]` B2 的 hiding 条件（修正 docs/17 旧 `m₂′>n′`）：按原文层级
`m₂′ > n+ℓ′`（承诺）→ `> n+ℓ′+1`（commit-and-prove，+1 来自 b^T/Rej2）→ `> n+ℓ′+λ+2(256/d+1)`（Thm5.3 simulatability）。**第二个「+1」和 λ、2(256/d+1) 不能省**——这直接否定旧稿 `m₂′>n′` 的简化（用户复核点）。

## E3. 参数可行域判断（符号级 + LBF 参数保守检查）

### E3.1 是否存在同时满足全部条件的参数区域

`[推导]` **存在（符号级）**：自由参数 (q, m₂′, n, α^(d),α^(e),γ1..γ4, c^(e), k_bin) 可协调：
1. 先按 C1 选 c^(e) < q/(41B^(e))——给定 q 与 α^(e)，c^(e) 有可行整数；
2. 按 E2c 选 m₂′ > n+ℓ+λ+2(256/d+1)（hiding）且 m₂′ 足够大使 MSIS_{n',…,B_aux} 难；
3. 按 C2/C3 选 q > max{(B^(e))²+√((υ_e+k_bin)d)·B^(e), 2(max β)²+(B^(e))²−1}；
4. α 参数按 L6726–6737 的 s 公式与拒绝抽样非中止概率（L6739–6765）协调（γ1..γ4 大⇒中止概率低但 s 大⇒ MLWE 实例松，需折中）。

**无硬矛盾**：C2/C3 只是给 q 下界，增大 q 总可满足（在格问题硬度允许范围内）。

### E3.2 与 LBF 原始参数的兼容性（保守检查）

```
LBF 参数（Table2）：d=128 → n+ℓ=27, m₂=53；d=64 → n+ℓ=35, m₂=83
B2：m₁*=m₁+m₂（m₁≈n），υ_e=(k+2)t（k,t 未选定）
```

`[推导]` 保守代入（**符号级，不虚报数值**）：
- Ajtai 消息从 m₁ 增到 m₁+m₂≈m₁+n（**约翻倍**）：Fig10 承诺 t_A=A₁s₁+A₂s₂ 的消息侧从 m₁ 列增到 m₁+m₂ 列；Extended-MLWE 秘密维度相应增大，但 hiding 条件 m₂′>n+ℓ+… 只约束**新盐** r，与 s₂ 的消息提升**正交**——故**不是**简单的"秘密维度翻倍破坏 hiding"；
- exact 关系数 υ_e=(k+2)t：C2 根号项约 √((k+2)t·d)。若 k,t 取 LBF 典型小值（如 k=t=1~4），υ_e~3~18，√ 项温和；若 k,t 大（10+），需重新评估；
- β_step5/β_step17 含 (m₁+m₂)d 量级（LBF Remark 4.8）；若按最坏 `(m₁+m₂)d` 读法，C3 的 q 下界按 (m₁+m₂)²d² 增长——**可能是主导瓶颈**，但确切表达式待官方 PDF 确认。

### E3.3 冲突不等式与增长量级

- 若 E2b 的 `Σp_i` 读法成立（C2 应代 υ_e·m₂），则 C2 根号项从 √((k+2)t·d) 增到 √((k+2)t·m₂·d)，约 ×√m₂（m₂=53/83 时约 ×7~9）——**显著抬高 q 下界**，可能压缩格硬度裕度；
- 若 β 按 (m₁+m₂)d 读法，C3 抬到 (m₁+m₂)²d² 量级——比 C2 更陡；
- 两者是否同时触发取决于 E2b 与 β 表达式的待核查结果。

### E3.4 代价落点

| 资源 | 增长来源 | 量级（符号） |
|---|---|---|
| 承诺大小 | s_A 增 m₂ 列 + υ_e 个余量 R_q 元素 + 辅助承诺 | +m₂ + υ_e 个 R_q 元素（每个 d·log q bit） |
| proof size | z^(e)（维数随 e^(e) 拼接长度）、c^(e) | 随 Σp_i+υ_e 增长；c^(e) 受 C1 限 |
| prover time | 多个 E_i 作用 + 拒绝抽样重抽 | 随 υ_e 线性 |
| verifier time | 多 E_i 验证 + MSIS/Extended-MLWE 参数变大 | 随 υ_e 线性 + q 增大 |
| 主导瓶颈 | β 的 (m₁+m₂)d 读法 + E2b 的 Σp_i 读法 | 可能使 q 与实例规模陡增（待核查确认） |

### E3.5 数值瓶颈结论

`[推导]` **不能宣称 128-bit**：本轮未完成 (a) β 官方表达式、(b) E2b 计数对账、(c) 具体 MSIS/Extended-MLWE hardness 估算（LBF 参数 + 新 m₁\*,υ_e）。在这些之前给出任何具体安全级别都是无依据的。**也没有证据表明 B2 在现实参数下必然不可行**——瓶颈是"待量化的增长"，不是"已证实的冲突"。
