## 1. 为什么原始采样分布不够

`[论文事实: §3.6, p.32, L2048–2050; §3.6 后 Protocol 7 讨论, p.42, L2795–2801]`

- 折叠步骤要输出 `z = Σ_i ρ_i z_i`（`ρ_i` 为 verifier 挑战）。`[推导]` 若直接输出，`z` 的分布是 witness 的线性函数，模拟器（只知实例）无法复现其分布 → 不 blinding。
- 论文逐字："Besides the changes regarding the commitments, we must modify our protocols by including a rejection sampling algorithm, in the spirit of [LNP22, Lemma 2.14]. **This is of utmost importance in order to achieve a blinding folding scheme.**"
- **技术症结**：Lemma 3.20 要求 mask `y` 与要藏的 secret `v` **独立**；但 `v:=Σ ρ_i z_i` 依赖 verifier 在看到 mask 承诺后才抽的 `ρ⃗`，因此 prover 必须**先于 `ρ⃗`** 采 `y←D_s^{n_F}`（Protocol 7 Step 3），并在 Step 10 算 `z=v+y`，Step 11 用 Rej1 过滤，使 `z` 的条件分布脱离 `v` 的具体取值。
- `[论文事实: Remark B.9, p.76–77]` 交互设定下拒绝轮**不被丢弃**，留在 verifier 视图中；条件于拒绝时 `y` 的分布被 `1−p(v)` reweighted，而 `p(v)` 依赖真实 witness `z₁` → 这是必须把 mask 的 Ajtai 像也 ABDLOP-承诺、仅在接受时打开的原因（§1.3/§3.1 contributions, p.6）。拒绝采样与 commit-and-prove 必须协同，缺一不可。

## 2. 目标分布与原始分布

`[论文事实: Lemma 3.20 ([LNP22, Lemma 2.4, Figure 1]), p.32–33, L2067–2083]`

- 设定：`V⊆R_F^ℓ` 为范数 ≤ `L·√n_F` 的多项式集合；`ρ:V→[0,1]` 任意概率分布；固定标准差 `s = ξ·L·√n_F`，`ξ>0`。
- **原始分布**：`v←ρ`、`y←D_s^ℓ`（离散高斯，center 0，std `s`；`[LNP22, Definition 2.1]`），`z=y+v`，得到联合分布 `(v,z)`（其中 `z` 依赖 `v`）。
- **目标分布**：乘积分布 `ρ × D_s^ℓ`，即 `z` 与 `v` **独立**、边缘为高斯。
- **保证**：Rej1 接受时，`(v,z)` 的分布与目标 `ρ×D_s^ℓ` 的统计距离 `≤2^{−λ}`；接受概率 `∈((1−2^{−λ})/M, 1/M]`，对每个 `v∈V`。
- **接受规则**（论文逐字，p.33 L2081）：`min{1, D_s^ℓ(z) / (M · D_{s,v}^ℓ(z))}`，对 `z←D_{s,v}^ℓ` 平均得上界 `1/M`。
- `Rej1(z,v,s)=1` 表示**重启**（沿用 [LNP22] 约定），`Rej1=0` 为接受。
- **重复率常数**：`M = exp(14/ξ + 1/(2ξ²))`，常数 14 来自 [LNP22, Lemma 2.14] 在 λ=128 的推导，λ=120 沿用（保守）。

`[推导]` 目标"z 独立高斯"正是模拟器可不依赖 witness 采样的分布；`ρ` 保持为"任意分布"是为了容纳 `v=Σρ_i z_i` 这种依赖秘密的复杂分布。

## 3. 哪些变量需要采样 / 接受条件 / 协议位置

### 3.1 采样变量

`[论文事实: Protocol 7 Step 3–11, p.42]`
- `y ← D_s^{n_F}`（唯一的高斯 mask；`ℓ=n_F`），**独立于任何其他挑战与采样值**；
- `c_y = L(y)`、`x_y = L_in(y)`、`y_{y,j}=M̄_j ŷ(r⃗)`（由 `y` 派生，**不被任何 `ρ_i` 缩放**）；
- 承诺 `C_{y,j}=Commit(y_{y,j}, s_{1,y,j}, s_{2,y,j})`、`C_{y,0}=Commit((c_y,x_y), s_{1,y,0}, s_{2,y,0})`（后者是 `Ñ=⌈(κ+n_{R,in})/ℓ⌉` 个承诺的元组，Remark 4.21, p.55）；
- `ρ₁,…,ρ_{K+k} ← C`（V 采样，每轮重采）；
- `v=Σ_i ρ_i z_i`、`z=v+y`；
- 判据 `Rej1(z,v,s)`。

### 3.2 接受条件与循环（`[论文事实]`，逐字结构）

```
2: while TRUE do
3:   P: y ← D_s^{n_F}
4–6: P: c_y,x_y,y_{y,j}; C_{y,j}; C_{y,0}
7:   P → V: C_{y,0}, {C_{y,j}}
8:   V: w++; if w > W_max then output ⊥ and halt
          else ρ₁..ρ_{K+k} ← C; send to P
9:   P: v ← Σ_i ρ_i z_i
10:  P: z ← v + y
11:  if Rej1(z,v,s) accepts then
12:    P → V: opening (c_y,x_y), s_{1,y,0}, s_{2,y,0} of C_{y,0}
13:    V: check C_{y,0}=Commit((c_y,x_y),·) and ‖s_{l,y,0}‖∞<B̃; else abort
14:    break
15–16: else retry (整块重采 mask，C_{y,0} 只在接受时打开)
```
`[论文事实: §2.1, p.9]` `W_max := ⌈λ / log₂(M/(M−1))⌉` 为公开固定的最大迭代次数；V 每轮重采 `ρ⃗`，故能强制该预算（Remark 4.3, p.42）。
`[论文事实: Remark 4.3]` **完备性上界**：诚实 prover 耗尽预算概率 `(1−1/M)^{W_max} ≤ 2^{−λ}` → 论文从 perfect completeness 降为 **statistical completeness**。`W_max` 是**最坏情况**预算并进入 knowledge-soundness；`M` 决定**期望**重试次数。

### 3.3 接受概率：理论 vs 期望 vs 实现数据

| 类别 | 数值/公式 | 出处与说明 |
|---|---|---|
| **理论上界** | `Pr[Rej1 accepts] ∈ ((1−2^{−λ})/M, 1/M]`；`(v,z)|accept` 与 `ρ×D_s^ℓ` 统计距离 `≤2^{−λ}` | Lemma 3.20, p.33 |
| 理论尾界 | `Pr[‖z‖>τ_{λ,ξ}s] < 2·ℓd·e^{−π τ_{λ,ξ}²}` | Lemma 3.19, p.32 |
| **期望迭代次数（非实测）** | ξ≈13 → ≈3 次；ξ≈20 → ≈2 次（λ=128 的 [LNP22] 设置，λ=120 沿用） | p.33 L2085–2086 |
| 最坏预算（λ=120） | `W_max=206`（M≈3）；`W_max=120`（M≈2）；λ=128：219 / 128 | Remark 4.3, p.42–43 |
| **实测数据** | **无**。论文明确把 §4.3.4 数字称为 *illustrative*，实现/基准列为未来工作（§5, p.59） | §4.3.3/§5 |

`[推导]` 切勿把 `≈2–3 次` 写成"实测 2–3 轮"或把渐近 `O(1)` 写成实际运行时间；它们是 [LNP22] 在 λ=128 下给出的期望值，论文直接沿用。

## 4. 参数 k 与约束规模的关系

### 4.1 标准差与 blinding 条件

`[论文事实: §3.6, p.32]`
```
s := ξ · (K+k) · T · (b−1) · √n_F        [文本提取注：镜像中 √ detached 于上一行；
                                          由 Lemma 3.20「s=ξL√n_F」与式 4.17 确定]
L := (K+k)·T·(b−1),  K=1=b−1 为本文用例
M = exp(14/ξ + 1/(2ξ²))
τ_{λ,ξ} ≥ √( (λ + log₂(2 n_F))·ln2 / π )
```
`[论文事实: Lemma 3.19]` λ=120 时 `τ≈5.50` (n_F=2¹⁶)、`5.58` (2²⁰)、`≈5.60` (2²¹，Remark 4.5)；λ=128 时 `5.657/5.734`。k 对 λ 只在平方根上敏感（128→120 改 τ 不到 3%）。

**blinding 条件**（`[论文事实: §3.6, p.32–33]`）：
```
τ_{λ,ξ} · s < B = b^k
即 τ_{λ,ξ} · ξ · (K+k) · T · (b−1) · √n_F < b^k      （Lemma B.1）
```

### 4.2 k 的渐近：Θ(log n_F) vs Θ(1)

`[论文事实: Remark 4.18, p.52]` 对比式：

| 方案 | 范数条件 | k |
|---|---|---|
| SuperNeo | `(K+k)·T(C)·(b−1) < b^k`（式 4.16） | `k=Θ(1)`；`T(C)=128,b=2,K=1` 时 `k=13` |
| LatticeBlindFold | `τ_{λ,ξ}·ξ·(K+k)·T(C)·(b−1)·√n_F < b^k`（式 4.17） | `k ≈ ½·log₂(n_F) + log₂(τ ξ (K+k)T(b−1)) = Θ(log n_F)` |

`[文本提取注]` 镜像把 `½` 印成 `12`；由 `√n_F` 与 `2^k` 取对数确定原式。Θ 结论不受影响。
`[推导]` 这就是任务包要的"k 与约束规模关系"：**k 由范数界 `B=b^k` 决定，不由 folding 深度决定**；√n_F 因子（高斯 mask 的宽度随维度增长）是 blinding 强加的，SuperNeo 没有。作者把 `Θ(log n_F)` 开销的 prover/verifier/communication 称为"the price of blinding"（p.52）。

### 4.3 具体 k 取值（`[论文事实: §3.6, p.33; Definition 3.1 布局]`）

主协议（K=1=b−1，blinding block 布局）：

| T | d | n_F | ξ≈13 | ξ≈20 |
|---|---|---|---|---|
| 128 | 64 | 2²¹ | 29 | 30 |
| 256 | 128 | 2²¹ | 30 | **31**（§4.3.4 使用） |

§4.3.4 参数集：`q=2⁶⁴−59`、`m=n_F=2²¹`、`ξ≈20`、`T=256,d=128` ⇒ `k=31`、`B=2³¹`、`B_fold=(K+k)T(B̃−1)+B̃=8194`。

**无累加器变体**（Corollary 4.24, p.57；见 §6）：`k_in=0` 时式 (4.20) `τ_{λ,ξ}·ξ·K·T(C)·(b−1)·√n_F < b^k` 中 `k` 不再出现在左端；同样 n_F=2²¹ 下 `k=24/25/25/26`，其中 `T=256,d=128,ξ≈20 ⇒ k=26`。

## 5. 额外成本来源（prover 与 verifier）

`[论文事实: §4.3.3, p.51–53; Remark 4.5, p.44; Remark 4.23, p.56–57]`

1. **循环本身**：每轮重采 `y`、派生 `c_y,x_y,y_{y,j}`、承诺 `C_{y,j},C_{y,0}`、发送与（接受时）打开；V 每轮重采 `ρ⃗` 并检查打开。`[推导]` 每轮至少一组 ABDLOP 承诺 + 一次 `L(y)` 环运算；被拒轮带来发送开销但不产生可用输出。
2. **W_max 预算进入可靠性**：`ε_cw = W_max(K+k)/|C|`（Proposition 4.17）；交互下 V 强制 `W_max`，FS 下被 `Q` 取代（Remark 4.26, p.59），d=64 参数集因此 `≈2^{−43}` 不可行。
3. **盐不能分解 → 承诺更宽**：Remark 4.5 量化 blow-up
   ```
   τ_{λ,ξ}·ξ·(K+k)·T(C)·(b−1)·√n_F / ((K+k)·T(C)·(B̃−1))
     = τ_{λ,ξ}·ξ·√n_F ≈ 2^{17.3}   (n_F=2²¹, ξ≈20, τ≈5.60)
   ```
   约 17 个高位盐为零 ⇒ ABDLOP 承诺退化，故 Π′DEC 改为 fresh resample 盐（p.44）。
4. **k 增大 ⇒ 一切按 k 缩放**：masked openings、输出承诺、Ajtai 承诺、PoK 数 `N_PoK=5+(K+k+1)t`（d=128: 104；d=64: 101）均随 k 增长。§4.3.3.1 给出的 illustrative 单步总大小：`d=128 ≈ 8.2 MB`、`d=64 ≈ 5.5 MB`（**分析估算，不是基准测试**）。
5. **完备性误差**：`ε_LBF^c ≤ 9·2^{−λ}`（batched 默认），其中含 Rej1 mask loop 的 `2^{−λ}` 与 ABDLOP PoK 内部重试项（Proposition 4.15, p.49）。
6. **blinding 误差的 8-bit 损失**：`O(W_max·2^{−λ}) = O(2^8·2^{−120}) ≈ 2^{−112}` 主导式 (4.6)，故 `ε^{LBF-blind}≈2^{−112}` 而非标称 `2^{−120}`（Remark 4.23）。

## 6. 减少采样开销的已有工作（论文自述）

`[论文事实: §5 Future work item (1), p.59, L3881–3889]`

## 7. 精确口径总结（避免误写）

| 结论类型 | 正确写法 | 错误写法 |
