## 0. 原文 binding 机制（精确复原）

### 0.1 Lemma 3.1 提取目标与四分量

`[论文事实: PDF L1541–1569]` Fig4 协议是 knowledge of `(s̄₁, s̄₂, c̄)` 满足：
```
(1) A₁s̄₁ + A₂s̄₂ = t_A
(2) ‖s̄ᵢ c̄‖ ≤ 2sᵢ√(2mᵢ d),  i=1,2          ← 提取界是 c̄-scaled，不是 ‖s̄ᵢ‖
(3) R₁s̄₁ + R_m(t_B − Bs̄₂) = u
(4) (MSIS 下) 该 (s̄₁,s̄₂) 唯一
```
其中 `s̄ᵢ = z̄ᵢ/c̄`，`c̄ = c−c′` 是两次回绕转录的挑战差（PDF L1659），`z̄ᵢ = zᵢ−z′ᵢ` 是 response 差，原文只对 `‖z̄ᵢ‖≤2sᵢ√(2mᵢd)` 给界（PDF L1718–1722）。

`[推导]` **关键点**：`s̄ᵢ` 本身**无界**——只有 `s̄ᵢc̄ = z̄ᵢ` 有界。`c̄` 是 R_q 元素、系数通常不小，`s̄ᵢ = z̄ᵢ/c̄` 在环中可除但**除法不保 ℓ₂ 范数**（除一个非单元素的算子范数可能 ≫1）。这是所有"不能写 ‖Δs‖≤2β"的根源。

### 0.2 binding 的"乘 c̄c̄′ 清分母"手法（逐字）

`[论文事实: PDF L1685–1701 式(25)(26), L1702–1717 式(27)]`
```
式(25): A₁s̄₁ + A₂s̄₂ = A₁s̄′₁ + A₂s̄′₂            （两个 opening 开同一 t_A）
式(26): A₁(s̄₁−s̄′₁)c̄c̄′ + A₂(s̄₂−s̄′₂)c̄c̄′ = 0       （乘 c̄c̄′ 清分母）
式(27): A₁(z̄₁c̄′−z̄′₁c̄) + A₂(z̄₂c̄′−z̄′₂c̄) = 0       （用 z̄ᵢ=s̄ᵢc̄ 改写）
```
`[推导]` 因为 R_q 交换，`s̄ᵢc̄c̄′ − s̄′ᵢc̄′c̄ = (s̄ᵢ−s̄′ᵢ)c̄c̄′`。**差向量带 c̄c̄′，不消去**：要证的唯一性正是 `s̄ᵢ=s̄′ᵢ`，若先假设相等就循环论证。乘 c̄c̄′ 的目的是把无界的 `s̄ᵢ` 换成有界的 `z̄ᵢ, z̄′ᵢ`。

`[论文事实: PDF L1740–1751]` MSIS 难 ⇒ `z̄ᵢc̄′−z̄′ᵢc̄ = 0` ⇒ `s̄ᵢ = z̄ᵢ/c̄ = z̄′ᵢ/c̄′ = s̄′ᵢ`。

### 0.3 界 B_LNP 与 8η 的来源

`[论文事实: PDF L1723–1739]`
```
B_LNP = 8η·√( (s₁√(2m₁d))² + (s₂√(2m₂d))² )
```
`[论文事实: PDF L1361–1364 Lemma 2.15, L1406–1420 式(21), L1456–1467 Fig.3]`
- `c∈C ⇒ ‖M_c‖_{2→2} ≤ η`；`c̄∈C̄ = c−c′ ⇒ ‖M_c̄‖_{2→2} ≤ 2η`（PDF L1723–1724 "multiplication by c̄ increases the norm by a factor of 2η"）。
- Fig.3 示例：`η=27`（σ₁，d=128,k=32）、`η=59`（σ₋₁）。
`[推导]` `‖z̄ᵢc̄′−z̄′ᵢc̄‖ ≤ ‖z̄ᵢc̄′‖+‖z̄′ᵢc̄‖ ≤ 2η‖z̄ᵢ‖+2η‖z̄′ᵢ‖ ≤ 2η·2sᵢ√(2mᵢd)·2 = 8η·sᵢ√(2mᵢd)`；两分量 ℓ₂ 合成得上式。**该界全程 c̄-scaled，基于 `‖s̄ᵢc̄‖≤2sᵢ√(2mᵢd)`**。

```
       = 8η·√( (s₁√(2m₁d))² + (ηβ)² )

B_aux  = √( B_{s₁,relaxed}² + B_{s₂,exact}² + B_{x,binary}² + B_{r,relaxed}² )
       = √( (8η·s₁√(2m₁d))² + (2β‖M_d̄M_d̄′‖_{2→2})²
             + (‖M_d̄M_d̄′‖_{2→2}·√(υe·d))² + (8η·s_r√(2m₂′d))² )
       ≤ √( (8η·s₁√(2m₁d))² + (8η²β)² + (4η²·√(υe·d))² + (8η·s_r√(2m₂′d))² )
```
`[推导 · LB-06R 任务 E]` 四项定义（同一 **R_q 系数的 Euclidean 嵌入**下）：
- `B_{s₁,relaxed}=8η·s₁√(2m₁d)`：原始 s₁，走原文 z 型拆项（§1.3a）；
- `B_{s₂,exact}=2β‖M_d̄M_d̄′‖≤8η²β`：**LB-06R 新补入**，s₂ 的 exact 单 opening 界经 d̄d̄′ 放大（§1.3b'）；旧稿把 s₂ 归进"relaxed"并实际省略，此处纠正；
- `B_{x,binary}=‖M_d̄M_d̄′‖·√(υe·d)`：υe 个二值余量 R_q 元素、每元素 d 系数、差∈{−1,0,1} 的保守 ℓ₂；若 B2 取 k_bin=0（docs/22 §E1C.2），此处的 υe 只数 exact 余量，不含 Eq.(54) 独立二值向量；若显式新增 k_bin 个 R_q 元素，须改为 `√((υe+k_bin)·d)`；
- `B_{r,relaxed}=8η·s_r√(2m₂′d)`：辅助承诺新盐 r，z 型拆项（§1.3d）。

`[推导]` `M_Ajtai=m₁+m₂+υe`（docs/22 §E1C），辅助 Ajtai 矩阵为 `M_Ajtai` 列、另加 randomness 的 `m₂′` 列；BDLOP 消息 ℓ′。故辅助 MSIS 实例应写 `MSIS_{n′, M_Ajtai+m₂′, B_aux}`，不再用旧记号 `m₁+m₂+υe+m₂'`（虽数值在 ν_x=υe 时相同，但记号须由 `M_Ajtai` 统一派生）。

### 1.5 exact 路线 vs relaxed 路线：不能断言 exact 更紧（本次新增发现）

`[推导]` 对 s₂ 分量，原文 relaxed 路线给 `8η·s₂√(2m₂d)`，B2 exact 路线给 `2β‖M_c̄M_c̄′‖`（保守 `8η²β`）。二者比值（用保守界）：
```
(8η²β) / (8η·s₂√(2m₂d)) = ηβ / (s₂√(2m₂d))
```
- 若 `ηβ < s₂√(2m₂d)`，exact 路线更紧；反之 relaxed 更紧。
- 原文 exact 界的意义是**单个提取 opening 的紧界**（用于后续把它当短 witness 传给折叠），而**不是**在 binding 双 opening 比较中自动更紧——后者仍乘 c̄c̄′。
- `[推导]` **结论**：exact-norm 的核心收益是"提取出的 s₂ 本身短（无 c̄），可作为下一轮短 witness 候选"，而不是"MSIS 差向量界更小"。把它写成"exact 覆盖 ⇒ MSIS 可用 exact β（无放大）"是错误的；正确写法见 §1.3(b)。这与用户任务 B 的判断完全一致，且给出量化比值。

## 2. 任务 C：三层 Binding 分证

### 2.1 第一层：原始 LBF commitment binding

`[论文事实: PDF L1731–1751 Lemma 3.1 st.4；LBF L1612–1627 Definition 3.15 拼接版]`

### 2.3 第三层：联合提取结果与原始 opening 的关联（B2 核心新增归约）
