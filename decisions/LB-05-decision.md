## 1. 最终决策

**B（条件性）：不新增承诺的直接扩展（路线 A）不可行；辅助承诺 + 联合一致性证明（路线 B）在数学原理上可行，但须满足 §4 的必要条件才真正闭合 s₂ 范数问题，任一关键条件被证伪即退回 LB-04 决策 C。**

`[推导]` 这是**方向性判定，不是"已验证可行"**。用户明确要求"不得默认 A/B"——本决策不是默认：A 被严格否证（§2），B 的"可行"建立在三条具体正面证据（§3）之上，且以显式条件与退回判据约束（§4）。B 的含义严格限于"存在无代数矛盾的清晰构造路径"，**不等于**已证明安全、已实例化、已算成本、已证递归。

## 2. 路线 A 否证（A = false）

`[推导]` 在保持 LBF 现有承诺布局、不新增承诺的边界下，无法把 `‖s₂‖₂≤β` 约束到原始 opening 的 s₂（docs/16）：
1. §5.2 exact-ℓ₂ 只作用于**已承诺消息** `s=(s₁,σ(s₁),m,σ(m))`（LNP L1679, L1690），s₂ 是 randomness、不在其中（LBF L3131–3133 "untouched by [LNP22]'s norm machinery"）。
2. 自内积证明要求 σ 配对；s₂ 没有，强行套用证错量（`‖a‖²+ν‖b‖²`，LBF L1841–1847）。
3. scalar anchoring 只保留 `Bs₂` 的常数项线性泛函（LBF L1645–1652 "no commitment is recomputed"），核维数巨大，不能恢复 m₂ 维 s₂。
4. Remark 4.8 的 append bound 维度 `(m₁+m₂)d` 与 Fig10 的 `2(m₁+ℓ)` 不符，"简单 append"不成立。

## 3. 路线 B 的三条正面证据（为何判 B 而非 C）

`[推导]` LB-04 的负面结论（决策 C）说"现有承诺布局下建立映射失败"，用户限定"新增承诺、改变布局是另一类问题"。本阶段证明这条路**没有结构性否定**，且有三条正面证据：

1. **原文先例**：LNP L2081 / Remark 6.2 明确用 "a separate ABDLOP commitment" 对 r、m 证 exact 范数以绕开 c̄；LNP L168 给出无自同构时"双承诺 + 线性关系"的强制路线。辅助承诺 `t'_A=A'₁s₂+A'₂r` 正是这两条原文机制的实例化（docs/17 §1.4）。
2. **避开 ν 陷阱**：s₂∈R_F（LBF L508–510 "Salts and commitments are always R_F-objects"），可用 base-ring 自同构 σ 配对直接证 `‖s₂‖²`，**不触发** LBF §3.3.4 的 R_K component-wise 分裂、不产生 `‖a‖²+ν‖b‖²` 错误量。这是 LBF 承诺约定给路线 B 的独特便利。
3. **同一性有结构性机制**：用户最担心的"新旧承诺 s₂ 是否同一"，在**单次联合 PoK 共享 witness** 形式下由 statement 变量结构保证——(R1)(R2) 与 (R3)(R5) 用同一个 s₂ 变量，MSIS 保证 witness 唯一（docs/17 §2.1–2.2）。这**绕开了** LB-04"需 m₂ 维约束"的障碍（该障碍只针对"两个独立证明 + 事后绑定"模型）。

`[推导]` 关键区分：LB-04 的 PC=I 是被**维度直接证伪**（m₂>n+ℓ，结构性）；路线 B 未发现此类结构性否定，其障碍是"待实例化/待证明"（§4），性质不同。故判 B 而非维持 C。

## 4. 条件性 B 的必要条件与退回判据

`[推导]` 路线 B 要真正闭合 s₂ 范数问题，须同时满足（docs/17 §6）：

| # | 条件 | 本阶段状态 |
|---|---|---|
| 1 | 联合 PoK (R1)–(R6) 可构造，s₂ 双重角色不破坏 reliability | **未证**（关键技术点） |
| 2 | 参数可实例化：m₂'>n'（hiding）、MSIS binding、Thm 5.3 界条件 `2β²+(B^{(eq)})²−1<q` | **未做**（无选定值） |
| 3 | 拼接矩阵 `[[A₁,A₂,0],[0,A'₁,A'₂]]` MSIS 硬度，短核为空 | **未证** [待核查] |
| 4 | 成本可接受：`(k+1)t + t` 份辅助承诺开销 | **未算**（只做符号级） |
| 5 | 递归场景：每轮联合 PoK + binding 识别同一 opening 的严格证明 | **未做**（本阶段只单次） |

**退回判据**：条件 1 或 3 任一被证伪（联合 PoK 不可构造，或拼接矩阵存在病态短核使两不同 s₂ 同时满足两组关系）→ 路线 B 结构性失败 → 退回 LB-04 决策 C。条件 2/4/5 属工程与递归层，不满足时维持"原理可行但未闭合"，不升级为"已验证可行"。
